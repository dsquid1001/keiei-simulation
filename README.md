# 経営シミュレーション

プレイヤー自身の経営判断によって会社が成長していく、ブラウザ型経営シミュレーションゲーム。

## Version 0.1

- 会社設立
- 商品設定
- 価格設定
- 広告
- 商品開発
- 市場調査
- 顧客数・売上・原価・利益の計算
- 市場変動
- 経済ニュース
- 経営履歴
- ブラウザ内セーブ（localStorage）

## 技術

- HTML
- CSS
- JavaScript
- GitHub Pages
- localStorage

## 開発方針

まず小さな経営ループを完成させ、その後に顧客セグメント、社員、競合、借入、投資家、経営者人格、会社文化などを段階的に追加する。
